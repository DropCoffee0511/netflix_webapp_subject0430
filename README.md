# Netflix Clone Project (넷플릭스 클론 사이트)

학원 과제를 위해 제작된 넷플릭스 스타일의 클론 웹사이트입니다. HTML과 CSS만을 사용하여 시맨틱한 구조와 프리미엄 디자인을 구현하는 데 중점을 두었습니다.

## 🚀 기술 스택
- **HTML5**: 시맨틱 태그(`header`, `main`, `section`, `footer`)를 활용한 구조 설계
- **CSS3**: 다크 모드 테마, Flexbox/Grid 레이아웃, 호버 애니메이션 효과

## ✨ 주요 기능
- **프리미엄 디자인**: 넷플릭스 고유의 다크 테마와 브랜드 컬러(Red) 적용
- **히어로 배너**: 강렬한 비주얼과 호출 버튼(CTA) 배치
- **인터랙티브 카드**: 영화 카드에 마우스를 올리면 확대되며 제목과 상세 정보 표시
- **반응형 웹**: 다양한 화면 크기에 대응하는 유동적인 레이아웃

## 📂 프로젝트 구조
- `index.html`: 웹사이트 구조
- `styles.css`: 디자인 및 스타일링
- `*.png`: AI로 생성된 고품질 영화 포스터 및 배경 이미지

## 💻 확인 방법
1. 이 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 브라우저로 엽니다.
